# HTTP Benchmark

**Консольная программа для проверки доступности HTTP-серверов и измерения времени выполнения запросов.**

## Возможности
- Проверка одного или нескольких HTTP/HTTPS-хостов.
- Выполнение заданного количества запросов к каждому хосту.
- Измерение времени выполнения каждого запроса.
- Расчёт минимального, максимального и среднего времени ответа.
- Подсчёт успешных запросов, запросов с HTTP-ошибками и ошибок соединения.
- Загрузка списка хостов из файла.
- Сохранение отчёта в файл или вывод в консоль.
- Конкурентное выполнение запросов с использованием потоков.
- Валидация входных параметров.


## Требования
- Python 3.12+
- requests - выполнение HTTP-запросов.

## Установка зависимостей:

`pip install -r requirements.txt`


## Запуск

Программа принимает аргументы командной строки для указания хостов, количества запросов и способа сохранения отчёта.

### 1. Указание хостов

Хосты, на которые будут выполняться запросы, можно передать одним из двух способов:

### 1.1 Через аргумент `-H`, `--hosts`

Можно указать один или несколько хостов через запятую:

`python http_benchmark.py -H https://ya.ru,https://google.com`

### 1.2 Через аргумент `-F`, `--file`

Загружает список хостов из текстового файла. Необходимо указать путь к файлу, содержащему список хостов, по одному адресу на строку.

Пример `test_data/hosts.txt`:
```
https://ya.ru
https://google.com
https://jsonplaceholder.typicode.com/posts
```
Запуск:

`python http_benchmark.py -F test_data/hosts.txt`

`-H` и `-F` являются взаимоисключающими — необходимо использовать только один из этих аргументов.

### 2. Количество запросов
`-C`, `--count`

Задаёт количество запросов, выполняемых к каждому хосту:

`python http_benchmark.py -H https://ya.ru,https://google.com -C 3`

По умолчанию выполняется 1 запрос к каждому хосту.

### 3. Сохранение отчёта
`-O, --output`

Указывает файл, в который будет сохранён итоговый отчёт:

`python http_benchmark.py -F test_data/hosts.txt -C 3 -O report.txt`

Если `-O` не указан, отчёт выводится в консоль.

## Примеры запуска

Проверить несколько хостов, отправив на каждый по одному запросу:

`python http_benchmark.py -H https://ya.ru,https://google.com`

Проверить несколько хостов, отправив 3 запроса на каждый:

`python http_benchmark.py -H https://ya.ru,https://google.com -C 3`

Загрузить список хостов из файла `test_data/hosts.txt`, выполнить по 5 запросов к каждому хосту и сохранить отчёт в `test_results/report.txt`:

`python http_benchmark.py -F test_data/hosts.txt -C 5 -O test_results/report.txt`


### Пример вывода
```
------------------------------
Host: https://google.com
Success: 3
Failed: 0
Errors: 0
Min: 1.231 s
Max: 1.309 s
Avg: 1.265 s
------------------------------
Host: https://ya.ru
Success: 3
Failed: 0
Errors: 0
Min: 1.147 s
Max: 1.157 s
Avg: 1.153 s
------------------------------
Host: https://jsonplaceholder.typicode.com/posts
Success: 3
Failed: 0
Errors: 0
Min: 0.535 s
Max: 0.550 s
Avg: 0.541 s
------------------------------
```
Поля отчета
- Host — URL тестируемого сервера, указанный пользователем.
- Success — количество запросов с успешным HTTP-ответом.
- Failed — количество запросов, на которые сервер ответил ошибкой (4xx или 5xx).
- Errors — количество запросов, которые не удалось выполнить из-за ошибки соединения, таймаута и других исключений.
- Min — минимальное время выполнения успешных запросов, в секундах.
- Max — максимальное время выполнения успешных запросов, в секундах.
- Avg — среднее время выполнения успешных запросов, в секундах.
